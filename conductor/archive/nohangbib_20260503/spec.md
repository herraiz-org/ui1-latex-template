# Specification: Configure Bibliography Hanging Indent

## Overview
Currently, the bibliography references have a hanging indent (the second and subsequent lines of an entry are indented), which is standard for APA style. However, the user wants the ability to align all lines of a reference flush left. This track will introduce a configurable option to the `ui1activity` document class to disable the hanging indent in the bibliography.

## Functional Requirements
- Introduce a new option (e.g., `nohangbib`) to the `ui1activity.cls` document class.
- When the `nohangbib` option is passed to the class, the bibliography generated by `biblatex` should not have a hanging indent; all lines of an entry should be aligned flush left.
- When the option is not present, the bibliography should retain the default APA-style hanging indent.

## Acceptance Criteria
- A test LaTeX document using the existing `referencias.bib` entry compiles with the default hanging indent when the `nohangbib` option is omitted.
- A test LaTeX document using the existing `referencias.bib` entry compiles with flush-left references when the `nohangbib` option is provided.
- The change is backwards-compatible and existing tests continue to pass.

## Out of Scope
- Changing the default APA style configuration other than the hanging indent.
- Modifying the formatting of other list environments (e.g., itemize, enumerate).
