\section{Matemáticas}

El tipo de descuento aplicado es del \(3,5\%\) anual: la coma decimal se
escribe tal cual y \texttt{icomma} corrige el espaciado, sin necesidad de
\verb|{,}|.

\begin{equation}
	\mathrm{VAN} = \sum_{t=0}^{n} \frac{F_t}{(1 + k)^{t}} - F_0
	\label{eq:van}
\end{equation}

La ecuación~\eqref{eq:van} descuenta los flujos \(F_t\) a la tasa \(k\).

\section{Código fuente}

\texttt{listings} no lo carga el class: se añade en el preámbulo del documento
cuando hace falta, con el estilo que se ve al principio de este archivo.

\begin{lstlisting}[language=Python, caption={Cálculo del VAN. / Computing NPV.}]
def van(flujos, k):
    """Valor actual neto de una serie de flujos de caja."""
    return sum(f / (1 + k) ** t for t, f in enumerate(flujos))
\end{lstlisting}
