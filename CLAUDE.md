## Build and test

Run from the repository root:

| Command | Effect |
|---|---|
| `make` / `make all` | Compiles `examples/plantilla.pdf` |
| `make slides` | Compiles `examples/presentacion.pdf` (two passes) |
| `make open` / `make open-slides` | Same, then `xdg-open` |
| `make test` | Compiles every fixture in `tests/latex/*.tex` |
| `make clean` | Removes build artefacts from the root and `examples/` |
| `make install` / `make uninstall` | texmf symlinks, `~/bin` CLIs, Agent Skills |

There is no `pdf` target at the root — `make pdf` only exists inside the directories
generated by `bin/new-activity` and `bin/new-slides`.

```bash
bash tests/run_tests.sh tests/shell/*.bats   # BATS suite, 129 tests
bash tests/shell/test_install.sh             # plain shell: install/uninstall
bash tests/shell/test_helvetica_cover.sh     # plain shell: cover page fonts
```

The Makefile runs `pdflatex` → `biber` → `pdflatex` ×2 whenever the source contains
`\addbibresource`, and two passes for slides so the section band and frame count settle.
Do not reduce this to a single pass.

## Hard constraints

From the original `ADE. Plantilla actividades 2026.docx`; changing any of them breaks
fidelity with the university template. Details and provenance in
[`specs/product-guidelines.md`](specs/product-guidelines.md).

- **Cover table width `144mm`** (8154 docx twips).
- **Page geometry**: `top=18mm, left=27.5mm, right=25mm, bottom=22mm, headheight=8pt,
  headsep=0pt, footskip=5mm`.
- **Backgrounds are mandatory**: `imgs/portada.png` on the cover, `imgs/interior.png`
  after it. Both are A4 portrait, 595.2 bp × 841.9 bp.
- **Palette**: `uired` `#E4004F`, `uigray` `#BFBFBF`, `uitableborder` `#D9D9D9`, and
  `uiframegray` `#E3E7E9` in the theme.
- **`hyperref` loads last** in `ui1activity.cls`, and must stay there.

## Conventions

- **Bilingual (ES/EN).** Comments, user-facing strings, and generated content are written
  for both Spanish and international readers.
- **Branding is strict** and deliberately not configurable. Body text is Palatino
  (default) or Times; headers are always Helvetica.
- **Expert audience.** Keep comments sparse and explain *why*, not *what*.
- **Interior pages stay free-form.** Resist adding opinionated section scaffolding.
- Use `git mv` for file moves.

### The `%` / `%%` rule in generated activities

`bin/new-activity` writes example blocks delimited by
`% --- BEGIN/END EJEMPLOS / EXAMPLES ---`. Inside them, **code lines start with `% ` and
prose lines with `%%`**, so stripping one comment level activates the code and leaves the
instructions commented. `tests/shell/activity_placeholders.bats` performs exactly that
strip and compiles the result; a prose line written with a single `%` breaks it.

The `\lstset` in those blocks is duplicated in `examples/plantilla.tex`. Change one,
change the other — `listings` is deliberately not loaded by the class, so both copies are
document-level setup.

## Working here

- Tests first: add or update a failing test in `tests/shell/*.bats` (with a fixture in
  `tests/latex/` when the change is LaTeX-side) before implementing.
- Run the full BATS suite plus `make test` before committing.
- CI (`.github/workflows/ci.yml`) runs shellcheck over `bin/`, the BATS suite inside
  `ghcr.io/xu-cheng/texlive-full`, and `make test`.
