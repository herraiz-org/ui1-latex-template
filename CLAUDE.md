# CLAUDE.md

Constraints and conventions for working on `ui1_template`. The [README](README.md) is
the user-facing documentation — CLI flags, bibliography entry types, and installation
live there and are not repeated here. This file records the things that are *not*
obvious from reading the code.

## Build and test

Run from the repository root:

| Command | Effect |
|---|---|
| `make` / `make all` | Compiles `examples/plantilla.pdf` |
| `make slides` | Compiles `examples/presentacion.pdf` (two passes) |
| `make open` / `make open-slides` | Same, then `xdg-open` |
| `make test` | Compiles every fixture in `tests/latex/*.tex` |
| `make clean` | Removes build artefacts from the root and `examples/` |
| `make install` / `make uninstall` | texmf symlinks, `~/bin` CLIs, Agent Skills |

There is no `pdf` target at the root — `make pdf` only exists inside the directories
generated by `bin/new-activity` and `bin/new-slides`.

Test suite:

```bash
bash tests/run_tests.sh tests/shell/*.bats   # BATS suite, 121 tests
bash tests/shell/test_install.sh             # plain shell: install/uninstall
bash tests/shell/test_helvetica_cover.sh     # plain shell: cover page fonts
```

The Makefile runs `pdflatex` → `biber` → `pdflatex` ×2 whenever the source contains
`\addbibresource`; slides get two passes so the section band and the slide count settle.
Do not replace this with a single pass.

## Hard design constraints

These come from the original `ADE. Plantilla actividades 2026.docx` and exist to keep
pixel fidelity with the university template. Do not change them without an explicit
request.

- **Cover table width: `144mm`** (8154 docx twips) — `ui1activity.cls`, in
  `\makecustomcover`. This exact value matches the original docx table.
- **Page geometry**, converted from docx twips (1 twip = 1/1440 in):
  `a4paper, top=18mm, left=27.5mm, right=25mm, bottom=22mm, headheight=8pt,
  headsep=0pt, footskip=5mm`. The margins are tuned against the background artwork —
  changing them moves body text off the printed frame.
- **Background image provenance**: `imgs/portada.png` is `word/media/image2.png` from
  the docx (cover), `imgs/interior.png` is `word/media/image1.png` (interior pages).
  Both are A4 portrait, 595.2 bp × 841.9 bp.
- **Colors**: `uired` `#E4004F`, `uigray` `#BFBFBF`, `uitableborder` `#D9D9D9`.

## Conventions

- **Bilingual (ES/EN).** Comments, user-facing strings, and documentation are written
  for both Spanish and international students.
- **Branding is strict.** The backgrounds are mandatory and must not be made optional.
  Decorative elements use `uired`/`uigray` only. Body text is Palatino (default) or
  Times; headers are always Helvetica.
- **Expert audience.** Keep comments sparse and explain *why*, not *what*. The class is
  meant to be read and extended by people who know LaTeX.
- **Interior pages are free-form.** Apart from the cover and the background underlays,
  the class imposes no structure — users organise the document with standard sectioning.
  Resist adding opinionated section scaffolding.
- Use `git mv` for file moves so history survives.

## Package roles in `ui1activity.cls`

Load order matters; the file is organised deliberately.

- `newpxtext`/`newpxmath` (Palatino, default) or `newtxtext`/`newtxmath` (Times),
  selected by the `palatino` / `times` class options. `helvet` is scaled to match —
  `0.95` with Palatino, `0.92` with Times — so the sans headers sit visually level with
  the body text.
- `titlesec` — sans-serif bold section headers.
- `babel` with `[english,spanish,es-tabla]` — Spanish is the default (hyphenation,
  "Tabla"), English is loaded so documents can `\selectlanguage{english}`. This dual
  setup is what powers the `\iflanguage`-based *Legislación* / *Legislation* heading.
- `icomma` — decimal comma in math mode.
- `parskip` — paragraph spacing; also reused as `\bibitemsep`.
- `csquotes` with `autostyle=true` — required by `biblatex`, follows the active language.
- `caption` — global caption style (`font={small,it}`, `labelfont=bf`, `margin=1cm`).
  Also loaded before `biblatex` to avoid the known conflict between the two.
- `biblatex` with `backend=biber, style=apa`. `\cite` is aliased to `\parencite`. The
  `nohangbib` option zeroes `\bibhang`. Custom drivers and a `\DeclareSourcemap` provide
  the `jurisprudencia` and `legislation` entry types — the source map runs *before*
  biber's data-model check, which is the only reason non-standard fields survive.
- `geometry` — the margins above.
- `xcolor` with `[table]` — loads `colortbl` implicitly; do not also load `colortbl`.
- `tabularx` — the fixed-width cover table.
- `fancyhdr` — empty header, page number bottom-right.
- `eso-pic` + `graphicx` + `ifthen` — full-page background underlay, `portada` on the
  cover and `interior` afterwards.
- **`hyperref` is loaded last, and must stay last.** It provides PDF bookmarks
  (`bookmarksdepth=3`, `hidelinks`) and fills PDF metadata from `\unidaddidactica`,
  `\alumno`, and `\asignatura` via an `\AtBeginDocument` hook.

When adding a package, record why it was chosen here.

**`listings` is deliberately not loaded by the class** — only documents that typeset
code need it, and loading it unconditionally would drag the dependency into every
activity. It belongs in the document preamble instead. `examples/plantilla.tex` shows
the branded `\lstset` (uired keywords, uigray frame), and `bin/new-activity` writes the
same block commented out into the generated `.tex`. The class still styles listing
captions, via the global `\captionsetup`. Keep those two copies of the `\lstset` in
sync.

## Generated-activity examples

`bin/new-activity` emits two comment blocks delimited by
`% --- BEGIN/END EJEMPLOS / EXAMPLES ---`: one for the preamble, one for the body,
covering figures, branded tables, equations, listings, and citations of the
`legislation` / `jurisprudencia` entries that `referencias.bib` ships commented out.

The convention that makes them work: **code lines start with `% `, prose lines with
`%%`.** Stripping one comment level activates the code and leaves the prose commented.
`tests/shell/activity_placeholders.bats` does exactly that strip, then compiles the
result — so the examples are verified to work when uncommented, not just to exist.
Adding a prose line with a single `%` will break that test.

## Beamer theme — `beamerthemeui1beamer.sty`

- **16:9 only.** `aspectratio` is a Beamer *class* option, so a theme file cannot set
  it. The theme compares `\paperwidth` against the expected width and issues a
  `\PackageWarning` when the slides are the wrong shape; documents must use
  `\documentclass[aspectratio=169]{beamer}`.
- **The decorative frame is redrawn, not reused.** `portada.png` and `interior.png` are
  A4 portrait (595.2 bp × 841.9 bp); stretched to 16:9 the logo and the interior footer
  text deform by roughly 26%. The theme therefore draws the frame with TikZ/`eso-pic`
  rectangles and reuses only the palette and Helvetica from the class.
- **The logo is cropped, not scaled**, out of `portada.png`:
  `\includegraphics[trim=70.6bp 726.2bp 382.6bp 70.6bp,clip]`. Those trim values are
  measured against the A4 artwork — they break if `imgs/portada.png` is ever replaced or
  resized.
- All frame dimensions are fractions of `\paperwidth`, so the layout survives a
  different slide size even though the theme asks for 16:9.

## Working here

- Tests come first: add or update a failing test in `tests/shell/*.bats` (with a fixture
  in `tests/latex/` when the change is LaTeX-side) before implementing.
- Run the full BATS suite plus `make test` before committing.
- CI (`.github/workflows/ci.yml`) runs shellcheck over `bin/`, the BATS suite inside
  `ghcr.io/xu-cheng/texlive-full`, and `make test`.
